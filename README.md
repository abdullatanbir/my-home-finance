# My Home Finance — Simple Personal Edition

A private, backend-free personal finance tracker. The app opens directly to the Dashboard and stores all financial data only in the browser/device.

## Run it

Install dependencies with `npm install`, then run `npm run dev`. For a production bundle, run `npm run build`.

## Phone installation and data safety

Open the app in a mobile browser and choose **Add to Home Screen**. The included manifest and service worker enable standalone/offline use after the first successful load. Export a JSON backup before changing phones, clearing browser data, or using a browser cleanup tool.

No account, password, online database, cloud storage, or server configuration is needed.
